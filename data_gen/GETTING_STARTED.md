# Centralized Parameter Comparison System - Complete Guide

## What Was Created

You now have a centralized system for comparing GARCH model parameters similar to `scaled_dataset.m`, with the following components:

### Core System (4 files)
1. **`compare_dataset.m`** - Main function to generate comparison datasets
2. **`compare_config.toml`** - Configuration file with all parameters
3. **`read_toml_config.py`** - Python helper to parse TOML files
4. **`rel_err_results.m`** - Enhanced analysis function

### Documentation (3 files)
5. **`COMPARE_README.md`** - Comprehensive documentation
6. **`COMPARE_SYSTEM_SUMMARY.md`** - Implementation summary
7. **`COMPARE_QUICK_REFERENCE.txt`** - Quick reference card

### Examples & Tests (3 files)
8. **`example_compare_usage.m`** - 5 usage examples
9. **`compare_config_duan_example.toml`** - Example Duan model config
10. **`test_compare_system.m`** - System verification test

## Configuration File (`compare_config.toml`)

All parameters are now in one file! Pre-populated with your actual values from:
- True parameters: hardcoded "market" values
- Initial parameters: from `compare/init.json`
- Calibrated parameters: from `compare/results_best1bin.json`

### Key Sections:

#### Model Selection
```toml
[model]
type = "HN"  # Options: "HN" (Heston-Nandi), "Duan", "GJR"
```

#### Noise Configuration
```toml
[noise]
level = 0.0   # 0.0 = no noise, 0.01 = 1%, 0.05 = 5%
seed = 42     # Random seed for noise
```

#### GARCH Parameters
```toml
[parameters.true]
omega = 1.0e-6
alpha = 1.33e-6
beta = 0.8
gamma = 5.0
lambda = 0.2

[parameters.initial]
omega = 1.0e-6
alpha = 1.5e-6
beta = 0.500000015
gamma = 1.0
lambda = 0.1

[parameters.calibrated]
omega = 9.254793490948722e-07
alpha = 1.2776396302437386e-06
beta = 0.7971227121160148
gamma = 6.608377980746554
lambda = 0.9726447064785998
```

## Common Use Cases

### Use Case 1: Basic Parameter Comparison
**Goal:** Compare true, initial, and calibrated parameters without noise

```matlab
% Default config already set up for this
compare_dataset('compare_config.toml')
rel_err_results()
```

### Use Case 2: Test Calibration Robustness with Noise
**Goal:** See how noise affects parameter comparison

1. Edit `compare_config.toml`:
```toml
[noise]
level = 0.02  # 2% noise
```

2. Run:
```matlab
compare_dataset('compare_config.toml')
rel_err_results('plot', true)
```

### Use Case 3: Compare Different Noise Levels
**Goal:** Study effect of 0%, 1%, 3%, 5% noise

1. Create 4 config files with different noise levels
2. Run each:
```matlab
compare_dataset('config_0pct.toml')  % outputs to folder specified in config
compare_dataset('config_1pct.toml')
compare_dataset('config_3pct.toml')
compare_dataset('config_5pct.toml')
```

3. Compare:
```matlab
rel_err_results('folder', 'compare_0pct', 'plot', true)
rel_err_results('folder', 'compare_1pct', 'plot', true)
rel_err_results('folder', 'compare_3pct', 'plot', true)
rel_err_results('folder', 'compare_5pct', 'plot', true)
```

### Use Case 4: Test Different Models
**Goal:** Compare HN vs Duan vs GJR models

1. Create separate configs for each model
2. Adjust parameters appropriately (Duan doesn't use gamma)
3. Run each and compare results

### Use Case 5: Generate Large Dataset
**Goal:** Create large dataset for machine learning

Edit config:
```toml
[scaling]
contracts_per_day = 100
num_days = 50
batch_size = 200
```

## Output Structure

### Generated by `compare_dataset()`
```
compare/  (or your specified output folder)
├── true_params.csv          # Dataset with true parameters
├── initial_params.csv       # Dataset with initial parameters
├── calibrated_params.csv    # Dataset with calibrated parameters
├── assetprices_true_params.csv        # Asset price paths
├── assetprices_initial_params.csv
└── assetprices_calibrated_params.csv
```

Each CSV has 12 columns:
- S0: Spot price
- m: Moneyness (K/S0)
- r: Risk-free rate
- T: Time to maturity
- corp: Call/Put flag (1=call, -1=put)
- alpha, beta, omega, gamma, lambda: GARCH parameters
- sigma: Implied volatility
- V: Option value

### Generated by `rel_err_results()`
```
compare/
├── rel_err_results.csv      # Analysis results table
└── rel_err_heatmaps.png     # Visualization (if plot=true)
```

## Analysis Output

The `rel_err_results()` function produces:

### 1. Mean Relative Error Tables
Groups results by:
- **Maturity:** <30 days, 30-180 days, >180 days
- **Moneyness:** <0.8, 0.8-1.0, 1.0-1.2, >1.2

Shows mean relative error for:
- Initial vs True
- Calibrated vs True

### 2. Improvement Metrics
Shows % improvement from calibration:
- Positive = calibration improved accuracy
- Negative = calibration made it worse

### 3. Summary Statistics
- Overall mean and median relative errors
- Total improvement from calibration

## Troubleshooting

### "Failed to read TOML config file"
**Solution:**
```bash
# Check Python
python3 --version

# Install TOML
pip install toml

# Test manually
cd data_gen
python3 read_toml_config.py compare_config.toml
```

### "Function not found" errors
**Solution:**
- Ensure all required .m files are in MATLAB path
- Run `test_compare_system` to check

### Memory errors
**Solution:**
- Reduce `contracts_per_day` or `num_days`
- Increase `batch_size`
- Close other MATLAB processes

### Pricing errors
**Solution:**
- Check GARCH parameters are valid (e.g., beta < 1)
- Verify tree parameters are appropriate
- Check maturity and moneyness ranges

## Tips and Best Practices

### 1. Start Small
Begin with small datasets to verify everything works:
```toml
[scaling]
contracts_per_day = 10
num_days = 5
```

### 2. Use Version Control
Keep your config files in git:
```bash
git add compare_config.toml
git commit -m "Add HN model config with 2% noise"
```

### 3. Name Config Files Descriptively
```
compare_config_hn_no_noise.toml
compare_config_hn_2pct_noise.toml
compare_config_duan_no_noise.toml
```

### 4. Document Your Experiments
Add comments to TOML files:
```toml
# Experiment: Test effect of 5% noise on calibration accuracy
# Date: 2026-03-31
# Expected: Higher noise should increase relative error
[noise]
level = 0.05
```

### 5. Save Results Systematically
Use different output folders:
```toml
[output]
folder = "results/experiment_1_no_noise"
```
