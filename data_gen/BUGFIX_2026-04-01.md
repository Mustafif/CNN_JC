# Bugfix: MATLAB String Multiplication Syntax Error

## Issue
`scaled_dataset_cached.m` had a syntax error on line 85:
```matlab
char("ON" * USE_PERSISTENT_CACHE + "OFF" * ~USE_PERSISTENT_CACHE)
```

This caused the error:
```
Error using *
Invalid data type. Argument must be numeric, char, or logical.
```

## Root Cause
MATLAB doesn't support string multiplication syntax like Python. The expression tried to multiply strings by boolean values, which is invalid.

## Fix Applied
Replaced lines 85, 87, and 89 with proper if-else conditionals:

**Before:**
```matlab
fprintf('  Persistent cache: %s\n', char("ON" * USE_PERSISTENT_CACHE + "OFF" * ~USE_PERSISTENT_CACHE));
fprintf('  Rebuild cache: %s\n', char("YES" * REBUILD_CACHE + "NO" * ~REBUILD_CACHE));
fprintf('  Pre-compute trees: %s\n\n', char("YES" * PRECOMPUTE_TREES + "NO" * ~PRECOMPUTE_TREES));
```

**After:**
```matlab
if USE_PERSISTENT_CACHE
    fprintf('  Persistent cache: ON\n');
else
    fprintf('  Persistent cache: OFF\n');
end
% ... similar for REBUILD_CACHE and PRECOMPUTE_TREES
```
