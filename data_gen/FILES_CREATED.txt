COMPARISON: OLD vs NEW
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

OLD SYSTEM (compare.m):
  - Parameters hardcoded in script
  - Manual JSON file loading
  - No noise simulation
  - Single model (HN)
  - Basic analysis
  - Minimal documentation

NEW SYSTEM (compare_dataset.m):
  - All parameters in TOML config
  - Automatic config loading
  - Built-in noise simulation
  - Multi-model (HN, Duan, GJR)
  - Enhanced analysis with filtering
  - Comprehensive documentation
  - Fair comparison guaranteed (same randomness)
  - Memory efficient (batch processing)

After running compare_dataset('compare_config.toml'):

  compare/
  ├── true_params.csv              # Options with true parameters
  ├── initial_params.csv           # Options with initial parameters
  ├── calibrated_params.csv        # Options with calibrated parameters
  ├── assetprices_*.csv            # Asset price paths (optional)
  ├── rel_err_results.csv          # Analysis results (after rel_err_results)
  └── rel_err_heatmaps.png         # Plots (if plot=true)

Each CSV contains:
  - S0, m, r, T, corp (market data)
  - alpha, beta, omega, gamma, lambda (GARCH parameters)
  - sigma (implied volatility)
  - V (option value)
