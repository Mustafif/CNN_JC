CONFIGURATION EXAMPLE
=====================

Edit compare_config.toml:

[model]
type = "HN"              # Model: HN, Duan, or GJR

[noise]  
level = 0.0              # 0.0=none, 0.02=2%, 0.05=5%
seed = 42

[parameters.true]
omega = 1.0e-6
alpha = 1.33e-6
beta = 0.8
gamma = 5.0
lambda = 0.2

[parameters.initial]     # From compare/init.json
[parameters.calibrated]  # From compare/results_best1bin.json

Then run:
  compare_dataset('compare_config.toml')
  rel_err_results()

TROUBLESHOOTING
===============

Problem: "Failed to read TOML"
→ Install: pip install toml
→ Test: python3 read_toml_config.py compare_config.toml

Problem: "Function not found"  
→ Run: test_compare_system (checks dependencies)
→ Ensure all .m files are in MATLAB path

Problem: IV solver issues
→ Run: test_impvol_fzero
→ Check inputs are reasonable
→ Try old solver for comparison

Problem: Memory errors
→ Reduce contracts_per_day or num_days in config
→ Increase batch_size
