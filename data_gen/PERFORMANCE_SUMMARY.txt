================================================================================

   ────────────────────

     • Uses parfor for contracts within batch
     • Speedup: ~3-4x on 4-core CPU

TROUBLESHOOTING
================================================================================

Slow Performance:
────────────────
✓ Check CPU usage (should be near 100%)
✓ Reduce NumWorkers if >100%
✓ Increase BatchSize
✓ Check disk I/O (use SSD)

Out of Memory:
─────────────
✓ Reduce BatchSize
✓ Use OptimizeMemory=true
✓ Process fewer parameter sets at once
✓ Add more RAM

Parallel Pool Errors:
────────────────────
✓ Close other MATLAB instances
✓ Restart MATLAB
✓ Check Parallel Computing Toolbox license

GPU Not Working:
───────────────
✓ Verify: gpuDevice() works
✓ Update GPU drivers
✓ Check CUDA compatibility
✓ Try UseGPU=false
