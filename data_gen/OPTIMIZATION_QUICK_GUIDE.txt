TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════

Problem: Slower than expected
Solution:
  ✓ Check CPU usage (should be near 100%)
  ✓ Increase BatchSize (try 500-1000)
  ✓ Reduce NumWorkers if CPU >100%


Problem: Out of memory
Solution:
  ✓ Reduce BatchSize (try 50-100)
  ✓ Process fewer parameter sets
  ✓ Use OptimizeMemory=true


Problem: Parallel pool won't start
Solution:
  ✓ Close other MATLAB instances
  ✓ Restart MATLAB
  ✓ Check PCT license
