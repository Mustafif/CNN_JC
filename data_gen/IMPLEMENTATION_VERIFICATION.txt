Main Processing Loop (lines 262-358):

✓ Inner loop: process all parameter sets with current noise
✓ Output file naming:
  - Single mode: dataset_hn.csv
  - Multi mode: dataset_hn_0pct.csv, dataset_hn_1pct.csv, etc.
✓ Parameter generation only on first iteration (efficient!)
✓ Asset files saved only once
✓ Performance report per noise level

Processing Flow:
```
if MULTI_NOISE_ENABLED:
  noise_levels = [0, 1, 5]
else:
  noise_levels = NOISE_LEVEL (single value)

for each noise_level:
    if first_iteration:
        generate 1 param_set (reused)
    
    for each param_set:
        process with current_noise_level
        save to dataset_Xpct.csv
    
    output performance report
```

Efficiency Analysis:
Before (3 separate runs):
  Run 1: Generate params, tree, contracts × 1 param, noise 0%
  Run 2: Generate params, tree, contracts × 1 param, noise 1%
  Run 3: Generate params, tree, contracts × 1 param, noise 5%
  Total: 3 param generations

After (1 run with multi-noise):
  Generate params once → reuse 3 times
  Process contracts × 3 noise levels
  Total: 1 param generation
  
Improvement: 66% reduction in param generation
