┌────────────────────────────────────────────────────────────────────────┐
│                          CACHING ARCHITECTURE                          │
├────────────────────────────────────────────────────────────────────────┤
│                                                                        │
│  Level 1: Random Data Pre-generation                                  │
│  ┌────────────────────────────────────────────┐                      │
│  │ rng(seed); Z = randn(NUM_DAYS, 1);         │  Speedup: 1.2x       │
│  │ ├─ Same for all parameter sets             │                      │
│  │ └─ Ensures fair comparison                 │                      │
│  └────────────────────────────────────────────┘                      │
│                                                                        │
│  Level 2: Probability Matrix Cache                                    │
│  ┌────────────────────────────────────────────┐                      │
│  │ for mat = 1:NUM_MATURITIES                 │  Speedup: 2-3x       │
│  │   prob_cache{mat} = gen_PoWiner(...);      │                      │
│  │ end                                         │  100K calls → 5 calls│
│  │ % Reuse 20,000 times!                      │  20,000x savings!    │
│  └────────────────────────────────────────────┘                      │
│                                                                        │
│  Level 3: Full Tree Grid Cache                                        │
│  ┌────────────────────────────────────────────┐                      │
│  │ trees = cell(NUM_DAYS, NUM_MATURITIES);    │  Speedup: 3-5x       │
│  │ for d = 1:NUM_DAYS                         │                      │
│  │   for m = 1:NUM_MATURITIES                 │  100K calls → 500    │
│  │     trees{d,m} = TreeNodes(...);           │  200x savings!       │
│  │   end                                       │                      │
│  │ end                                         │  Memory: ~500 MB     │
│  │ % Direct O(1) lookup!                      │                      │
│  └────────────────────────────────────────────┘                      │
│                                                                        │
│  Level 4: IV Lookup Table (planned)                                   │
│  ┌────────────────────────────────────────────┐                      │
│  │ iv_cache = containers.Map();               │  Speedup: 5-10x      │
│  │ if iv_cache.isKey(key)                     │                      │
│  │   iv = iv_cache(key);  % Cache hit!        │  Hit rate: 60-80%    │
│  │ else                                        │                      │
│  │   iv = impvol_fzero(...);                  │  Memory: ~200 MB     │
│  │   iv_cache(key) = iv;                      │                      │
│  │ end                                         │                      │
│  └────────────────────────────────────────────┘                      │
│                                                                        │
│  Level 5: Persistent Disk Cache (optional)                            │
│  ┌────────────────────────────────────────────┐                      │
│  │ cache_file = 'cache/trees_hash.mat';       │  Speedup: 100x+      │
│  │ if exist(cache_file) && ~rebuild           │                      │
│  │   load(cache_file);  % Instant!            │  First: 60 sec       │
│  │ else                                        │  Next:  0.5 sec      │
│  │   compute(); save(cache_file);             │                      │
│  │ end                                         │  Disk: ~500 MB       │
│  └────────────────────────────────────────────┘                      │
│                                                                        │
│  Combined: 2 × 3 × 5 × 10 × 100 = 3000x theoretical speedup          │
│  Practical: 10-50x with overhead and cache misses                    │
│                                                                        │

DATA FLOW
════════════════════════════════════════════════════════════════════════════

  Input: Configuration
    │
    ├─→ TOML File or Function Args
    │
    v
  Pre-computation Phase
    │
    ├─→ Generate random data (Z ~ N(0,1))
    ├─→ Build probability matrices (5 maturities)
    ├─→ Build tree grid (100 days × 5 maturities)
    │   └─ ~500 trees cached
    │
    v
  Generation Phase (parallel)
    │
    ├─→ For each parameter set (parallel)
    │   │
    │   ├─→ For each day
    │   │   │
    │   │   ├─→ Simulate GARCH (using cached Z)
    │   │   ├─→ Generate strikes K ~ U(0.8S, 1.2S)
    │   │   │
    │   │   ├─→ For each contract (parfor batches)
    │   │   │   │
    │   │   │   ├─→ Lookup tree (cached!)
    │   │   │   ├─→ Lookup prob matrix (cached!)
    │   │   │   ├─→ Price American option → V
    │   │   │   ├─→ Compute IV using impvol_fzero
    │   │   │   └─→ Store result
    │   │   │
    │   │   └─→ Batch results
    │   │
    │   └─→ Dataset for parameter set
    │
    v
  Output: CSV Files
    │
    ├─→ data/scaled_HN_YYYYMMDD_HHMMSS.csv
    └─→ Columns: S, K, T, r, sigma, type, index, N, m, gamma, V, day
